# 重启24（工作名）

24 小时重启系统的仪式引导器。设计文档见 [DESIGN.md](./DESIGN.md)。

**线上地址：<https://langrenxdh.github.io/restart24/>**（GitHub Pages 免费托管，push `main` 自动部署）

## 当前：M1–M4（心跳 / 接力 / 保护 / 回望）

- **晨间启动**：3 步身体唤醒 + 写下今天唯一的 MIT（下午后自动切换为 30 秒压缩版）；**昨夜锚点自动预填**，只确认或微调，If-Then 原话回显
- **深度执行**：每轮专注必须先写「这一轮我交付 ___」；25/45 分钟计时；「卡住了」给降级动作，不换方向；基于时间戳计时，刷新/锁屏不漂移，可恢复
- **午间复位**：三行复位卡（上午完成什么·自动带入 / 下午一件事 / 几点开始）+ 可选粗锚点；TodayCard 显示下午安排和铁律「上午做什么，下午继续做什么」
- **失控日应急**：首页常驻「今天崩了」入口，22 点未交付时升级为温柔提醒；三步流程：压缩成 10 分钟版 → 内置 10 分钟计时 → 记录灰色胜利 + 明日锚点；**链条不断**
- **赢的时刻**：记录今日可见交付物 → 「我赢了」；应急日为灰色变体「今天守住了」；连续天数含灰色胜利，页眉常驻连胜数
- **赢后继续**：胜利锁定后可「继续做事」——再开专注轮、追加任意多个成果，全部入档（复利不算义务）
- **任务池**：晨间 MIT 可从池中选（绑定后完成自动勾掉）；晚间流程对没完成的 MIT 强制三选一处置（顺延明天 / 放回池 / 放弃）；管理入口在成果墙第三页签。池子是明天的候选清单，不是义务清单
- **晚间复合流程**（20 点后开放入口，约 45 分钟）：复盘 5 问 → 记录今日成果（没有就砍成 10 分钟版）→ 写明日第一项任务（时间 + 成果 + 位置）→ 前夜清障清单 → 写一条 If-Then（可复用规则库）→「明天见」
- **锚点跨天接力**：昨夜写下的任务和时间，就是今晨的第一张卡
- **成果墙**：月历热力图（绿=赢 / 灰=灰色胜利 / 空=未记录），点开看当天交付物、专注轮次、复盘摘要
- **规则库**：If-Then 规则管理，使用次数统计；**数据**：JSON 全量备份/导入（覆盖式）+ 本周 Markdown 周报导出
- **PWA**：可安装到主屏（Safari 分享 → 添加到主屏幕 / Chrome 菜单 → 安装应用），全屏 standalone 运行，Service Worker 离线可用
- **应用内提醒**：20 点晚间流程 / 22 点未交付兜底的横幅 + 页面通知（桌面与 Android 尽力而为）
- 本地优先：数据存在浏览器 IndexedDB（Dexie），无账号无后端

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
npm run typecheck
```

手机体验：dev server 已开 LAN 访问，同一 Wi-Fi 下用 `http://<电脑IP>:5173` 打开。

## 提醒的现实边界（重要）

浏览器对网页通知限制严格，尤其是 iOS。本应用的策略：

1. **应用内横幅**：App 开着时，20 点提醒晚间流程、22 点提醒 10 分钟版兜底——这条最可靠
2. **页面通知**：桌面 Chrome / Android 上可开启（安装引导卡片里），App 开着时弹系统通知
3. **系统闹钟兜底（推荐）**：给晨间配一个系统闹钟（如 7:00）。这不妥协——设计文档明确「晨间通知需要系统闹钟兜底」，闹钟响 + 打开主屏图标，两步进入今天的 MIT
